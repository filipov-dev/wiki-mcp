# Документация wiki-mcp

`wiki-mcp` — MCP-сервер (stdio или HTTP) и CLI для Yandex Wiki Public API. Краткое описание и быстрый старт — в [README](../README.md).

| Страница | О чём |
| --- | --- |
| [Установка и обновление](install.md) | Установочный скрипт, Homebrew, готовые архивы и `SHA256SUMS`, Windows, сборка из исходников, платформы, удаление. |
| [OAuth-приложение и токен](oauth.md) | Собственное приложение Яндекс OAuth, права `wiki:read` и `wiki:write`, приложение на каждого агента, IAM-токен, отзыв токена. |
| [IAM-токены](iam.md) | Федеративные и сервисные аккаунты Yandex Cloud: токены из `yc iam create-token` или по ключу сервисного аккаунта, автоматическое обновление, хранение ключа. |
| [Подключение к MCP-клиентам](clients.md) | `connect` для Claude Code и Codex, ручное подключение других клиентов (Antigravity, Kimi Code, ZCode и любых со stdio), профили, отключение. |
| [HTTP-режим](http.md) | `serve --http` для машин без системного хранилища и удалённых клиентов: токен в заголовке запроса, Docker, Compose, systemd, подключение агентов, модель угроз. |
| [Справочник CLI](cli.md) | Все команды и флаги: `connect`, `serve`, `auth`; профили, тип токена, организация, переменные окружения. |
| [MCP-инструменты](tools.md) | Все инструменты по наборам, уровни доступа, частые задачи, аргументы и ответы, постраничная выдача, `upload_attachment`, `wait_for_operation`, `api_search`, `api_request`. |
| [Безопасность](security.md) | Хранение токена и права, вырезание учётных данных из ответов, доступ к локальным файлам, протокол и логи. |
| [Решение проблем](troubleshooting.md) | Homebrew tap, Keychain, Secret Service в Linux, SSH, ошибки `401`, `403` и `404`, загрузка файлов, большие ответы. |
| [Переход со старого HTTP-сервера на TypeScript](migration.md) | Соответствие старых инструментов `wiki_*` новым, отличия аргументов, проверка на тестовой странице, переключение и откат. |
| [Разработка](development.md) | Структура крейтов, проверки, пересборка спецификации API. |
