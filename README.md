# wiki-mcp

MCP-сервер и CLI для [Yandex Wiki Public API](https://yandex.ru/support/wiki/ru/api-ref/). Даёт Claude Code, Codex и другим MCP-клиентам читать, создавать и править страницы Wiki, дописывать текст в разделы, прикладывать и скачивать файлы, комментировать, работать с динамическими таблицами, копировать и восстанавливать страницы.

- **Все операции API — MCP-инструменты.** Они генерируются при сборке из официальной OpenAPI-спецификации Wiki API с дополнением (короткие имена, уровни доступа, описания из справочника); `api_search` находит нужную операцию, `api_request` вызывает любую в пределах уровня доступа.
- **Составные инструменты.** `upload_attachment` загружает локальный файл вложением страницы одним вызовом (сессия загрузки, части, прикрепление), `wait_for_operation` дожидается фонового копирования или переноса страниц.
- **Токен — только в системном хранилище** (macOS Keychain, Secret Service в Linux, Credential Manager в Windows), отдельный профиль и токен для каждого агента. OAuth-токен выдаёт ваше собственное OAuth-приложение Яндекса; ни переменные окружения, ни `.env`, ни конфигурация клиента его не содержат. Исключение — HTTP-режим (ниже): там токен агента приходит в заголовке каждого запроса и сервер его не хранит.
- **По умолчанию только чтение.** Запись и удаление включаются явно; инструменты выше разрешённого уровня агенту не видны.
- **Учётные данные не попадают к агенту.** Токены, пароли и ключи в ответах Wiki, в том числе в тексте страниц и ячейках таблиц, заменяются на `[redacted]`.

Сервер работает через stdio: MCP-клиент сам запускает `wiki-mcp serve`. Для Linux-машин без системного хранилища и клиентов, которые подключаются по адресу, есть [HTTP-режим](docs/http.md) (`serve --http`, в том числе в Docker).

## Установка

### Установочный скрипт (Linux и macOS)

```bash
curl -fsSL https://codeload.sourcecraft.tech/filipov-dev/wiki-mcp/tarball/refs/heads/install | tar -xzO | sh
```

Скрипт ставит последнюю версию в `~/.local/bin` без `sudo` и сверяет архив с `SHA256SUMS` релиза; повторный запуск обновляет бинарник. Параметры (`--version`, `--prefix`) — в [docs/install.md](docs/install.md#установочный-скрипт).

### Homebrew (macOS и Linux)

```bash
brew tap filipov-dev/tap https://git.sourcecraft.dev/filipov-dev/homebrew-tap.git
brew install filipov-dev/tap/wiki-mcp
```

Tap размещён на SourceCraft, поэтому `brew tap` нужен полный адрес. Устанавливайте формулу по полному имени `filipov-dev/tap/wiki-mcp`.

### Готовый архив

Архивы для macOS (универсальный, подписан и нотаризован), Linux x86_64 и aarch64 (статические, без зависимостей) и `SHA256SUMS` — на [странице релизов](https://sourcecraft.dev/filipov-dev/wiki-mcp/releases).

### Из исходников

```bash
cargo build --release
```

Бинарник: `target/release/wiki-mcp`. Нужен Rust 1.88 или новее и C-компилятор.

Подробнее, включая проверку контрольных сумм, обновление и удаление: [docs/install.md](docs/install.md).

## Быстрый старт: Claude Code и Codex

```bash
wiki-mcp connect claude-code
# или
wiki-mcp connect codex
```

`connect` поможет создать собственное OAuth-приложение Яндекса (откроет форму и подскажет настройки), спросит организацию (Yandex 360 или Yandex Cloud), откроет ссылку получения токена, примет токен скрытым вводом, проверит его и сохранит в системное хранилище под профилем с именем клиента. Затем покажет, что изменится в конфигурации клиента, и после подтверждения зарегистрирует сервер `wiki`. Перезапустите клиент.

Права задаются при подключении и попадают в команду запуска сервера:

```bash
wiki-mcp connect codex --allow-write
```

Агенту, которому достаточно чтения, создайте приложение только с правом `wiki:read`: даже если сервер работает только на чтение, токен с правом записи опасен при утечке. Подробнее: [docs/oauth.md](docs/oauth.md).

## Другие MCP-клиенты

`connect` настраивает только Claude Code и Codex. Любой другой клиент со stdio-серверами подключается вручную:

1. Сохраните токен и организацию в отдельный профиль: `wiki-mcp auth login --profile cursor`.
2. Зарегистрируйте в клиенте stdio-сервер с командой `wiki-mcp` и аргументами `serve --profile <профиль>`:

   ```json
   {
     "mcpServers": {
       "wiki": {
         "command": "/opt/homebrew/bin/wiki-mcp",
         "args": ["serve", "--profile", "cursor"]
       }
     }
   }
   ```

   Укажите в `command` абсолютный путь из `command -v wiki-mcp`. Чтобы разрешить запись или удаление, добавьте в `args` `"--allow-write"` или `"--allow-destructive"`.

Пути к конфигурации и особенности Google Antigravity, Kimi Code и ZCode — в [docs/clients.md](docs/clients.md#google-antigravity).

## HTTP-режим

```bash
docker compose up --build -d   # или: wiki-mcp serve --http
claude mcp add --transport http wiki http://127.0.0.1:8767/mcp \
  --header "Authorization: OAuth <токен>" \
  --header "X-Org-Id: <ID организации>"
```

Сервер ничего не хранит: токен и организация приходят в каждом запросе, токен уходит только в Wiki API. Токен виден агенту в конфигурации клиента, поэтому граница безопасности здесь — права токена, а флаги доступа сервера — страховка от ошибок. Локальные файлы в HTTP-режиме выключены. Подробнее: [docs/http.md](docs/http.md).

## Уровни доступа

| Уровень | Как включить | Что доступно |
| --- | --- | --- |
| Чтение | по умолчанию | Только инструменты, которые читают данные, в том числе поиск по Wiki и скачивание вложений. |
| Запись | `--allow-write` | Создание и изменение: страницы, текст, комментарии, таблицы, загрузка файлов, копирование, перенос и восстановление страниц. |
| Удаление | `--allow-destructive` (включает запись) | Удаление страниц, вложений, комментариев, таблиц и изменение прав доступа к страницам. |

Инструменты выше разрешённого уровня не регистрируются: агент их не видит и не может вызвать. `--toolsets` выбирает разделы API: по умолчанию включены страницы, вложения, комментарии и таблицы (`pages`, `attachments`, `comments`, `grids`); права доступа к страницам (`access`) и операции, которых нет в справочнике (`extra`: перенос страниц, история версий, обратные ссылки), включаются явно, `--toolsets all` включает все. Подробнее: [docs/tools.md](docs/tools.md).
